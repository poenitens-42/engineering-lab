# Engineering Lab Portfolio

Minimal personal portfolio for Arjun Prabhakaran.

## Edit Projects

Project cards are generated from `projects.js`. Update `window.PORTFOLIO_PROJECTS`
to change featured repos, copy, categories, and links.

The browser also tries to enrich repository update dates from the public GitHub API.
If that request fails, the curated fallback dates remain visible.

## Deploy

This is a static site. Deploy the folder containing `index.html` to GitHub Pages,
Netlify, Vercel, or any static host.
